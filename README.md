# 안녕하세요, 웹개발자 방병호입니다 👋

공공기관 웹서비스를 개발·운영하며 사용자에게 안정적인 서비스를 제공하는 웹개발자입니다.

ASP.NET WebForms, MSSQL, IIS를 기반으로 한 유지보수와 기능 개선을 중심으로 경험을 쌓았고, Java Spring과 Python을 활용한 웹 애플리케이션 및 모니터링 도구도 개발하고 있습니다.

## 주요 기술

- **Backend:** ASP.NET WebForms, C#, Java Spring, Python
- **Database:** MSSQL, MyBatis
- **Frontend:** HTML, CSS, JavaScript, Blazor
- **Server & Tools:** IIS, Tomcat, Docker, Git
- **관심 분야:** 웹서비스 운영, 성능 개선, 로그 분석, 보안

## 주요 프로젝트

### DocNote
PDF·HWP 문서를 보면서 필기와 메모를 남길 수 있는 노트 애플리케이션입니다.

- 문서 뷰어와 필기 도구를 결합한 모바일 앱
- Pen, Eraser, Highlighter, Lasso, Shape, Text 기능 구성
- Flutter 기반 UI 및 사용자 경험 개선

### Pulse
뉴스와 키워드를 수집·분석해 주요 이슈를 보여주는 뉴스 대시보드입니다.

- 뉴스 수집 및 키워드 기반 이슈 클러스터링
- 대표 제목과 중립적인 이슈 제목 분리
- Flutter 기반 모바일 애플리케이션

### Monitoring Blazor
운영 데이터를 확인하고 분석하기 위한 모니터링 대시보드입니다.

- Blazor 기반 대시보드
- 로그와 운영 지표 확인
- 반복 업무를 줄이기 위한 화면 및 기능 개선

### Helpdesk
업무 요청과 처리를 관리하기 위한 Java 기반 웹 애플리케이션입니다.

- Spring 기반 웹 애플리케이션
- 업무 데이터 관리 및 조회 기능
- 유지보수하기 쉬운 구조를 목표로 개발

## 경력 방향

공공기관 웹서비스 운영 경험을 바탕으로 안정성, 유지보수성, 성능을 고려한 웹서비스를 개발합니다. 새로운 기술을 무작정 적용하기보다 운영 환경과 사용자 요구를 분석해 실질적인 개선으로 연결하는 것을 중요하게 생각합니다.
